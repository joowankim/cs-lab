복습 화면

cs-lab 실험을 복습할 때 쓰는 설명용 화면을 모은다. 실험 코드와 측정 결과는 저장소에 있다.

01 동시성 모델 비교

  • 동시성 관계도전체 지도 아래에 장면 여섯(Python 계산, 네이티브 계산, time.sleep() 대기, 공유 카운터와 Lock, 루프 지연, Task와 Semaphore)의 관계도, 코드, 모든 단계를 한눈에 보는 띠를 둔다. 관계도의 요소를 누르면 개념, 지금 상태, 근거가 나온다.

화면은 설명용 모형(model.js)으로 움직인다. 단계는 이벤트의 순서이고 시간 길이가 아니다. 실측값은 "실험에서 잰 값" 칸과 실측 기록 표시가 붙은 근거에만 있고, 모두 실험 README의 결과에서 옮겼다. 화면을 만든 방법과 점검 결과는 화면 README에 적었다.

03 MySQL 격리 수준과 MVCC

  • MVCC 관계도전체 지도 아래에 장면 일곱(스냅숏을 만드는 때, 잔액 세 번 읽기, 잠그며 읽기, 동시 차감, 열어 둔 트랜잭션, InnoDB와 MyISAM, 커밋을 디스크에)의 관계도, SQL, 모든 단계를 한눈에 보는 띠를 둔다. 표 안에 행 버전과 락, 스냅숏이 보는 버전을 그리고, 관계도의 요소를 누르면 개념, 지금 상태, 근거가 나온다.
