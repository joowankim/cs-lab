복습 화면

cs-lab 실험을 복습할 때 쓰는 설명용 화면을 모은다. 실험 코드와 측정 결과는 저장소에 있다.

01 동시성 모델 비교

  • 동시성 관계도시험판전체 지도 아래에 장면 셋(공유 카운터와 Lock, 루프 지연, Task와 Semaphore)의 관계도와 모든 단계를 한눈에 보는 띠를 둔다.
  • 동시성 실행 애니메이션실행 그래프, 코드, 공유 상태, 로그 네 칸이 같은 단계를 함께 보여 준다.
  • Python 실행 구조 관계도자세한 설명장면, GIL, 프로세스·스레드·CPU 수를 바꿔 가며 요소마다 개념, 현재 상태, 관련 코드, 근거를 읽는다.

세 화면은 같은 모형(model.js)으로 움직이는 설명용 모형이다. 단계는 이벤트의 순서이고 시간 길이가 아니다. 실측값은 실측 기록 표시가 붙은 곳에만 있고, 모두 실험 README의 결과에서 옮겼다. 화면을 만든 방법과 점검 결과는 화면 README에 적었다.
