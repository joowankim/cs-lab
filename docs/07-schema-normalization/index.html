    구성 고르면 처음 단계부터 다시 본다

    관계도

    • 지금 따지는 행
    • 찾은 짝, 쥔 락
    • 이 단계에 들어간·바뀐 행
    • 이상, 대기, 오류
    • 읽었지만 쓰지 않음
    • 값이 단계에 본 칸

    코드

      모든 단계 칸을 누르면 그 단계로 간다

        볼 것
          실험에서 잰 값 (모형과 별개)

            실험 README의 결과에서 옮겼다. 관계도의 단계 수와 개수는 모형 표의 값이라 이 값과 비례하지 않는다.

            근거와 복습 카드
                설명용 모형이다. 단계는 이벤트의 순서이고 시간 길이가 아니다. 실측값은 "실험에서 잰 값" 칸에만 있다. 화면을 만든 방법, 모형의 가정, 점검 결과는 화면 README에 적었다.
