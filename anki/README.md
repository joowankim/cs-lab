# 복습 카드

실험에서 배운 내용을 앞면·뒷면 형식으로 정리한다. 현재는 문서로 보관하고, Anki로 옮기는 작업은 나중에 한다.

파일은 `NN-name.md`로 만들고 실험 번호를 맞춘다. 카드 ID는 `NN-001`부터 붙이며, 수정할 때도 유지한다. 각 앞면에는 다른 카드 없이 답할 수 있도록 필요한 조건을 적는다.

뒷면은 복습용으로 정리한 답이다. 사람이 실제로 답한 내용과 이해 수준은 각 실험 README에 따로 보존한다. 측정값이 나온 문제는 숫자 암기보다 결과 해석에 초점을 둔다. 실측값과 설명용 가상 숫자를 구분한다.
