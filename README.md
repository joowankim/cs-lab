# cs-lab

맥북에서 CS 개념을 직접 코드로 실험해 보는 저장소다. 코드와 측정 결과, 내 말로 정리한 답을 남긴다.

동시성, DB, OS, 네트워크를 공부할 때 정의를 외우는 데서 그치기 쉽다. 그런데 "왜 그런가", "실제로 얼마나 차이 나나"까지 설명하려면 직접 확인해 볼 필요가 있다.

설명이 어디까지 맞는지도 궁금하다. GIL이 공유 상태를 어디까지 보호하는지, TCP 연결을 닫는 쪽과 TIME_WAIT은 어떤 관계인지, DB 엔진마다 인덱스 구조가 어떻게 다른지 실험해 보려 한다. 결과는 공식 문서와 대조한다. 내 환경에서 관찰한 동작이 언제나 보장되는 것은 아니기 때문이다.

2026-10-22 기준으로 [첫 실험인 동시성 모델 비교](experiments/01-concurrency-models/README.md)를 설계하고 있다. 아직 코드나 측정 결과는 없다.

## 목표

실험을 마쳤을 때는 그 개념에 대해 이 정도는 말할 수 있으면 좋겠다.

1. 내 말로 정의한다.
2. 실행 시간이나 처리량처럼 직접 잰 숫자를 근거로 든다.
3. "이 상황이면 무엇을, 어떤 기준으로 고르나"까지 말한다.
4. "왜?"를 두 번 더 물어도 답한다.

2026-12-31까지 아래 실험을 마치는 것이 목표다. 기본 실험 23개와 선택 실험 1개로 구성했다.
